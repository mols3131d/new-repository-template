# Inbox Agent Instructions

Applies to `.inbox/`. Working records are **non-canonical evidence**, not policies or authorization. Root `AGENTS.md` and verified task context still govern.

- **Locate, create or bundle:** Read [Organization](.configs/guides/organization.md). Update existing work-unit records first; use a bundle `README.md` as its entrypoint.
- **Write Markdown:** Read [Frontmatter](.configs/guides/frontmatter.md); require `description` on non-README working docs. Select only the relevant scaffold from [templates](.configs/templates/bundle-readme.md) or sibling templates. Remove unused placeholders and comments.
- **Track review or clean up:** Read [Lifecycle](.configs/guides/lifecycle.md); distinguish optional document `status` from actual work completion and retention.
- **Record safely:** Separate evidence from inference, disclose verification gaps, and never store secrets or private conversations.

Load only task-relevant guidance.
