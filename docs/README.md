# Documentation

This starter reserves clear ownership for common documentation subjects without assuming a product, framework or delivery process. Add topic documents and narrower directories only when the derived project has material to maintain.

| Area | Responsibility |
| --- | --- |
| [Goals](goal/README.md) | Intended outcomes, requirements, scope and acceptance criteria |
| [Architecture](architecture/README.md) | Component boundaries, design decisions and technical tradeoffs |
| [Development](development/README.md) | Contributing, local development, verification and development practices |
| [Documentation](documentation/README.md) | Writing standards, frontmatter metadata and index generation |
| [Policies](policies/README.md) | Adopted project-wide policies not already owned by instructions or settings |
| [Tools](tools/README.md) | Tool selection, setup, configuration, commands and update boundaries |

For an unfamiliar topic, use the generated [documentation index](INDEX.tsv) to choose an area by `path` and `description`, then follow its entrypoint. For a known owner, go directly to it. The index is navigation data, not an instruction source.

The repository [README](../README.md) provides first-use instructions and [AGENTS.md](../AGENTS.md) owns the agent working baseline. This index routes documentation but does not replace either.
