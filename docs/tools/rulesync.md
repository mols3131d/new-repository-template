# Rulesync

This template uses [Rulesync](https://rulesync.dyoshikawa.com/) to install selected upstream Skills and generate agent-specific Rules, Commands, Subagents, and Skills. Setup and synchronization run through [mise tasks](mise.md).

Agent Asset selection and lifecycle are covered by [Agent Asset Lifecycle](../development/agents/assets.md).
