# Operations

Keep procedures for **deploying, operating and recovering** the derived project here once it has a real runtime: environment-specific deployment steps, routine maintenance, observability, incidents, backup and recovery.

Do not invent cloud providers, runbooks, production checks or service-level guarantees for this template. Contributor tooling and CI development checks belong in [Development](../development/README.md); instructions for end users belong in [Guides](../guides/README.md). Record executable operational commands only after validating them against the real system.
