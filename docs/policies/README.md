# Policies

Use this area for **adopted, cross-cutting project policies** that need their own durable explanation, such as a language or disclosure policy. Add a policy document only when the derived project has actually chosen that policy.

Check existing owners first: [AGENTS.md](../../AGENTS.md) governs agent instructions and authorization; [Development](../development/README.md) owns contributor workflows; [Tools](../tools/README.md) owns tool practices and configuration. Repository settings, executable configuration and platform permissions remain authoritative for what is technically enforced.

A written policy does not by itself configure a check or grant permissions. Link to any enforcement source and avoid duplicate rules. The starter imposes no additional project policy through this directory.
