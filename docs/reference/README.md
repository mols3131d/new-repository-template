# Reference

Keep stable, **lookup-oriented contracts** for the derived project here: APIs, CLI arguments, configuration keys, schemas and externally visible data formats.

The template has no application API or schema yet. Add references when real interfaces exist, using the implementation or native schema as the authoritative source whenever possible. Avoid manually duplicating automatically derived inventories or turning tutorials into reference pages; practical walkthroughs belong in [Guides](../guides/README.md).
